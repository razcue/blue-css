Blue has no class names, so it cannot collide with Tailwind's. What matters is the cascade: Blue must lose to your utilities and win over Tailwind's reset.

## Layer order

Declare it once, before importing either:

```css [main.css]
@layer theme, base, blue, components, utilities;
@import "tailwindcss";
```

- **Utilities beat Blue.** Add `mt-8` or `bg-red-500` to any element and it applies.
- **Blue beats preflight.** Tailwind's reset sits in `base`; Blue styles on top of it. Build with `reset: false` (or `--no-reset`) to drop Blue's own reset.
- **Everything is `:where()`.** Blue's selectors have zero specificity at the top level, so even unlayered CSS of yours wins.

## shadcn components are left alone

shadcn and shadcn-vue put `data-slot` on every component. Blue skips those elements, so a shadcn `<Button>` keeps exactly the classes it ships with — while a plain `<button>` next to it is styled by Blue.

## One theme for both

Blue uses **shadcn's variable names** as its design tokens: `--background`, `--foreground`, `--primary`, `--muted`, `--border`, `--ring`, `--radius` and the rest. Blue declares defaults inside `@layer blue.tokens`; a shadcn theme is normally unlayered `:root {}` CSS, and unlayered CSS beats any layer. So **your existing shadcn theme restyles Blue automatically.**

See every token on [Tokens](/reference/tokens).

## Dark mode

Tokens use `light-dark()`, so Blue follows the OS by default. The shadcn `.dark` class or `data-theme="dark"` forces dark; `.light` or `data-theme="light"` forces light — on the root or any subtree.

::blue-example
```html
<div data-layout="grid">
  <article data-theme="light">
    <header><h3>Light</h3><p>Forced with data-theme.</p></header>
    <footer><button>Save</button><span data-badge data-variant="secondary">draft</span></footer>
  </article>
  <article data-theme="dark">
    <header><h3>Dark</h3><p>Same markup, same tokens.</p></header>
    <footer><button>Save</button><span data-badge data-variant="secondary">draft</span></footer>
  </article>
</div>
```
::

## Opting out

Wrap anything Blue should not touch in `data-blue="off"`. Every module except the reset and tokens is scoped with `@scope (:root) to ([data-blue="off"])`.

::blue-example
```html
<p><button>Styled by Blue</button></p>
<p data-blue="off"><button>Left alone</button></p>
```
::
