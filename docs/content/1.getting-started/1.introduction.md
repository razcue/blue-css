Blue CSS is a classless CSS framework for **solo developers building MVPs**. You write good, semantic, accessible HTML; Blue styles it. There are no classes to learn and no stylesheet to write.

::blue-example
```html
<article>
  <header>
    <h3>Create project</h3>
    <p>Deploy your new project in one click.</p>
  </header>
  <label>Name <input placeholder="my-app"></label>
  <footer>
    <button data-variant="outline">Cancel</button>
    <button>Deploy</button>
  </footer>
</article>
```
::

Every preview on this site is that: plain HTML, rendered with the real Blue stylesheet.

## Why it exists

Classless frameworks such as Pico or Simple.css stop at documents. An MVP needs **app UI**: an app shell, forms, tables, menus, dialogs, tabs, toasts. Blue covers those from HTML alone, and adds what a production app needs:

| Problem | What Blue does |
|---|---|
| Writing and maintaining CSS for every screen | Styles native elements, ARIA state and structure: `<main>`, `<article>`, `<dialog>`, `role="tablist"`, `aria-invalid`. |
| A big framework for a small app | Ships only the modules your build output uses, measured on real pages. |
| Fighting Tailwind or shadcn | Lives in its own cascade layer with zero-specificity selectors; skips shadcn components; shares their tokens. |
| Headless libraries look unstyled | Styles ARIA widgets by role, and bare reka-ui primitives through a preset. |
| Markup that only exists at runtime | `blue-css doctor` renders your pages and lists what was shaken away. |

## Principles

- **HTML is the API.** Native elements first, ARIA for state, then a [closed set of five data attributes](/reference/data-attributes).
- **Structure means layout.** The element containing `<main>` is the app shell; `<article>` is a card; `nav > ol` is a breadcrumb.
- **Low specificity, layered.** Everything lives in `@layer blue.*`, top-level selectors in `:where()`. Your classes always win.
- **Ship what you use.** Every module declares the markup that triggers it; the build keeps only those.
- **Modern browsers.** `:has()`, `@layer`, `@scope`, nesting, `light-dark()`, `@starting-style`, popover.
