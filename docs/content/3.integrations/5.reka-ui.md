`@blue-css/preset-reka` styles reka-ui's unstyled primitives from what reka renders: its `data-state` and `data-side` attributes, its `data-reka-*` markers and the CSS variables it writes inline. Core already styles the ARIA parts — tabs, menus, listboxes, switches, checkboxes, toggles — so the preset adds positioning, overlays, animations and the parts with no ARIA semantics.

```js
import reka from '@blue-css/preset-reka'

blue({ presets: [reka] })                                    // Vite
export default defineNuxtConfig({ blue: { presets: ['@blue-css/preset-reka'] } })  // Nuxt
```

## Use primitives as they are

```vue
<DialogRoot>
  <DialogTrigger>Edit profile</DialogTrigger>
  <DialogPortal>
    <DialogOverlay />
    <DialogContent>
      <header>
        <DialogTitle>Edit profile</DialogTitle>
        <DialogDescription>Make changes to your profile here.</DialogDescription>
      </header>
      <form>…</form>
      <footer>
        <DialogClose data-variant="outline">Cancel</DialogClose>
        <button type="submit">Save changes</button>
      </footer>
      <DialogClose aria-label="Close">×</DialogClose>
    </DialogContent>
  </DialogPortal>
</DialogRoot>
```

## Covered

Accordion, AlertDialog, Avatar, Checkbox, Collapsible, Combobox, ContextMenu, Dialog, DropdownMenu, HoverCard, Label, Menubar, Popover, Progress, RadioGroup, ScrollArea, Select, Separator, Slider, Switch, Tabs, Toast, Toggle, ToggleGroup, Toolbar and Tooltip.

Each preset module triggers on a marker in reka's bundled code, so it ships only when your app imports the component that renders it: a Select-only app gets select and popper styles, but no accordion, dialog or toast CSS.

## Recipes to know

- **Avatar:** reka renders bare `<span>`s; give the root the semantics an avatar needs anyway — `<AvatarRoot role="img" aria-label="Ada Lovelace">`.
- **Progress:** set the indicator transform as reka's docs show: `:style="{ transform: \`translateX(-${100 - value}%)\` }"`.
- **Dialog close button:** a `DialogClose` placed directly in `DialogContent` (outside `header` and `footer`) becomes the corner "×".
- **Variants** work on reka parts too: `<DialogClose data-variant="outline">`, `<DropdownMenuItem data-variant="destructive">`.

Every covered primitive renders in `packages/preset-reka/playground` (`?c=dialog`, `?c=select`, …).
