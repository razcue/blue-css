```bash
pnpm add -D @blue-css/cli
```

## Commands

```bash
blue-css build [content...] [options]   # scan built output, write only the CSS it uses
blue-css full [options]                 # write the complete stylesheet
blue-css scan [content...] [--json]     # show which tokens and modules were detected
blue-css doctor <target...> [options]   # render pages, report styles that were shaken away
```

Content is globs or directories of your **built** output — HTML, JS chunks, JSON payloads. Run it after your framework's build:

```bash
vite build && blue-css build dist -o dist/assets/blue.css --report
```

## Options

| Option | |
|---|---|
| `-o, --out <file>` | Output file (default: `out` from the config, else stdout) |
| `-c, --config <file>` | Config file (default: `./blue.config.{js,mjs}`) |
| `-s, --safelist <ids>` | Comma-separated module ids or tokens to always ship |
| `--preset <name>` | Add a preset package (repeatable) |
| `--no-reset` | Drop Blue's reset |
| `--no-minify` | Readable output |
| `--report` | Print a size and module report |

## Config file

```js [blue.config.mjs]
import { defineConfig } from '@blue-css/engine'

export default defineConfig({
  content: ['dist'],
  out: 'dist/assets/blue.css',
  safelist: ['details'],
  presets: ['@blue-css/preset-reka'],
})
```
