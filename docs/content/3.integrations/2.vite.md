```js [vite.config.js]
import blue from '@blue-css/vite'
import vue from '@vitejs/plugin-vue'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [vue(), blue()],
})
```

## What it does

- **`vite dev`** serves the full stylesheet at `/@blue-css/blue.css` and links it from `index.html`.
- **`vite build`** scans the final, in-memory bundle — every JS chunk, including what libraries in `node_modules` render — plus the HTML entry points, then emits `assets/blue-<hash>.css` and links it. The file name changes whenever the shipped CSS changes.

```
blue-css assets/blue-C14Wq4ME.css: 9 modules shipped, 13 shaken · 17.4 kB (4.7 kB gzip)
```

## Options

Same as [Nuxt](/integrations/nuxt) (`safelist`, `content`, `presets`, `reset`, `minify`, `report`), plus:

| Option | Default | |
|---|---|---|
| `inject` | `true` | Link the stylesheet from `index.html` |

## SSR frameworks

Without an `index.html` to inject into, pass `inject: false` and read the result from the plugin:

```js
const plugin = blue({ inject: false })
// after the client build:
plugin.api.href      // "/assets/blue-C14Wq4ME.css"
plugin.api.result    // sizes, shipped and shaken modules
```
