The **app shell** is whichever element directly contains `<main>`: `<body>`, or the wrapper a framework mounts into (`#app`, `#__nuxt`). Its direct `header`, `aside`, `main` and `footer` children form the page.

## Header, main, footer

A sticky header, centered content, a footer. The first link or heading in the header is the brand.

::blue-example{height="340" padding="0"}
```html
<header>
  <a href="#">Acme</a>
  <nav>
    <ul>
      <li><a href="#" aria-current="page">Dashboard</a></li>
      <li><a href="#">Customers</a></li>
      <li><a href="#">Settings</a></li>
    </ul>
  </nav>
</header>
<main>
  <header>
    <hgroup>
      <h1>Dashboard</h1>
      <p>Overview of your business this month.</p>
    </hgroup>
    <menu>
      <li><button data-variant="outline">Export</button></li>
      <li><button>New invoice</button></li>
    </menu>
  </header>
  <p>Page content.</p>
</main>
<footer>
  <small>© 2026 Acme Inc.</small>
</footer>
```
::

- `main > header` is a **page header**: an `hgroup` for title and description, a `menu` for actions.
- `aria-current="page"` marks the active link.

## Sidebar

Add an `<aside>` to the shell and it becomes a full-height sidebar. `<nav>` sections inside it stack vertically; a heading before a list labels it. Below 48rem it turns into a scrolling bar above the page.

::blue-example{height="400" padding="0"}
```html
<aside>
  <a href="#">Acme Inc.</a>
  <nav aria-label="Platform">
    <h2>Platform</h2>
    <ul>
      <li><a href="#" aria-current="page">Dashboard</a></li>
      <li><a href="#">Customers</a></li>
      <li><a href="#">Invoices</a></li>
    </ul>
  </nav>
  <footer><small>ada@acme.dev</small></footer>
</aside>
<header>
  <nav aria-label="Breadcrumb">
    <ol>
      <li><a href="#">Home</a></li>
      <li aria-current="page">Dashboard</li>
    </ol>
  </nav>
  <menu><li><input type="search" placeholder="Search…" aria-label="Search"></li></menu>
</header>
<main>
  <h1>Dashboard</h1>
  <p>The sidebar is the &lt;aside&gt;; nothing else is needed.</p>
</main>
```
::

## Breadcrumbs and menus

Inside `<nav>`, an ordered list is a **breadcrumb** and an unordered list is a **menu**. Two lists split into a navbar.

::blue-example
```html
<nav aria-label="Breadcrumb">
  <ol>
    <li><a href="#">Home</a></li>
    <li><a href="#">Projects</a></li>
    <li aria-current="page">Blue CSS</li>
  </ol>
</nav>
<nav>
  <ul><li><strong>Acme</strong></li></ul>
  <ul>
    <li><a href="#" aria-current="page">Home</a></li>
    <li><a href="#">Pricing</a></li>
    <li><a href="#">Docs</a></li>
  </ul>
</nav>
```
::

## Secondary column

An `<aside>` inside `<main>` becomes a sticky side column on screens 64rem and wider.

## Opting out of the shell

The shell is pure CSS on structure. Any utility class or your own CSS on these elements wins; `data-blue="off"` removes Blue from a subtree entirely.
