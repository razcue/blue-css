Wrap a control in its `<label>`; put help text in a `<small>` after it. A form stacks its fields with consistent gaps.

::blue-example
```html
<form>
  <label>Email <input type="email" placeholder="ada@example.com"></label>
  <label>
    Username
    <input value="ada" aria-invalid="true" aria-describedby="u-help">
    <small id="u-help">This username is already taken.</small>
  </label>
  <label>About <textarea placeholder="Tell us about yourself"></textarea></label>
  <button type="submit">Save</button>
</form>
```
::

- `aria-invalid="true"` (or the browser's `:user-invalid` after interaction) turns the field and its help text red.
- Textareas grow with their content where `field-sizing` is supported.

## Choices

::blue-example
```html
<fieldset>
  <legend>Notifications</legend>
  <label><input type="checkbox" checked> Email me about new invoices</label>
  <label><input type="radio" name="f" checked> Daily digest</label>
  <label><input type="radio" name="f"> Weekly digest</label>
  <label><input type="checkbox" role="switch" checked> Marketing emails</label>
</fieldset>
```
::

`role="switch"` on a checkbox renders a switch.

## Selects, ranges and files

::blue-example
```html
<form>
  <label>Plan
    <select><option>Hobby</option><option selected>Pro</option><option>Enterprise</option></select>
  </label>
  <label>Volume <input type="range"></label>
  <label>Avatar <input type="file"></label>
  <label>Start date <input type="date"></label>
</form>
```
::

## Layout and groups

`data-layout="grid"` on a fieldset puts fields in columns; `role="group"` joins an input and a button.

::blue-example
```html
<form>
  <fieldset data-layout="grid">
    <label>First name <input placeholder="Ada"></label>
    <label>Last name <input placeholder="Lovelace"></label>
  </fieldset>
  <fieldset role="group">
    <input type="email" placeholder="Subscribe to updates" aria-label="Email">
    <button>Subscribe</button>
  </fieldset>
</form>
```
::

## Sign-in page

A lone `<article>` in `<main>` that contains a `<form>` becomes a narrow, centered card — a complete sign-in page with no CSS.

::blue-example{height="560" padding="0"}
```html
<main>
  <article>
    <header>
      <h1>Sign in to Acme</h1>
      <p>Enter your email below to sign in.</p>
    </header>
    <form>
      <label>Email <input type="email" placeholder="m@example.com"></label>
      <label>Password <input type="password"></label>
      <label><input type="checkbox" checked> Remember me</label>
      <button type="submit">Sign in</button>
      <button type="button" data-variant="outline">Sign in with GitHub</button>
    </form>
  </article>
</main>
```
::
