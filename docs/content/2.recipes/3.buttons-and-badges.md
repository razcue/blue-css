## Variants

`<button>` is primary. `data-variant` picks another look; `type="reset"` is outline by default.

::blue-example
```html
<div data-layout="row">
  <button>Primary</button>
  <button data-variant="secondary">Secondary</button>
  <button data-variant="outline">Outline</button>
  <button data-variant="ghost">Ghost</button>
  <button data-variant="destructive">Destructive</button>
  <button data-variant="link">Link</button>
  <a role="button" href="#">Link as button</a>
</div>
```
::

## Sizes and states

::blue-example
```html
<div data-layout="row">
  <button data-size="sm">Small</button>
  <button>Default</button>
  <button data-size="lg">Large</button>
  <button data-size="icon" aria-label="Add">+</button>
  <button aria-busy="true">Saving</button>
  <button disabled>Disabled</button>
</div>
```
::

- `aria-busy="true"` shows a spinner and blocks clicks.
- `disabled` or `aria-disabled="true"` dims the button.

## Groups

`role="group"` joins buttons and inputs.

::blue-example
```html
<div role="group" aria-label="View">
  <button data-variant="outline">Day</button>
  <button data-variant="outline">Week</button>
  <button data-variant="outline">Month</button>
</div>
```
::

## Toolbars

A `<menu>` lays out actions in a row.

```html
<menu>
  <li><button data-variant="outline">Export</button></li>
  <li><button>New invoice</button></li>
</menu>
```

## Badges

`data-badge` on any inline element.

::blue-example
```html
<div data-layout="row">
  <span data-badge>Default</span>
  <span data-badge data-variant="secondary">Secondary</span>
  <span data-badge data-variant="outline">Outline</span>
  <span data-badge data-variant="destructive">Destructive</span>
  <span data-badge data-variant="success">Paid</span>
  <span data-badge data-variant="warning">Pending</span>
</div>
```
::
