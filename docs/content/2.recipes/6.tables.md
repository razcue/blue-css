Wrap a table in a `<figure>` to give it a border and horizontal scrolling on small screens.

::blue-example
```html
<figure>
  <table>
    <caption>Recent invoices</caption>
    <thead>
      <tr>
        <th scope="col">Invoice</th>
        <th scope="col">Customer</th>
        <th scope="col">Status</th>
        <th scope="col" aria-sort="descending">Amount</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>INV001</td><td>Liam Johnson</td>
        <td><span data-badge data-variant="success">Paid</span></td><td>$250.00</td>
      </tr>
      <tr aria-selected="true">
        <td>INV002</td><td>Olivia Smith</td>
        <td><span data-badge data-variant="outline">Pending</span></td><td>$150.00</td>
      </tr>
      <tr>
        <td>INV003</td><td>Noah Williams</td>
        <td><span data-badge data-variant="destructive">Overdue</span></td><td>$350.00</td>
      </tr>
    </tbody>
    <tfoot>
      <tr><td colspan="3">Total</td><td>$750.00</td></tr>
    </tfoot>
  </table>
</figure>
```
::

- `aria-selected="true"` on a row highlights it.
- `aria-sort` on a header shows the sort direction.
- Numbers use tabular figures; a cell holding only a checkbox, button or menu shrinks to fit.
