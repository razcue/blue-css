Blue styles widgets by their **ARIA roles and states**, so the same CSS covers reka-ui, Radix, Ark, Headless UI or hand-written markup. Wire the behavior with your library of choice; the look comes from the semantics.

## Tabs

::blue-example
```html
<div role="tablist" aria-label="Account">
  <button role="tab" aria-selected="true">Account</button>
  <button role="tab" aria-selected="false">Password</button>
  <button role="tab" aria-selected="false" disabled>Billing</button>
</div>
<div role="tabpanel"><p>Make changes to your account here.</p></div>
```
::

## Menus and listboxes

Items highlight on hover, focus, `aria-selected` or the `data-highlighted` attribute libraries set. A role-less child is a label; `aria-haspopup="menu"` adds a submenu chevron; checked items show a check.

::blue-example
```html
<div role="menu" aria-label="Account">
  <div>My account</div>
  <div role="menuitem" tabindex="-1">Profile <kbd>⇧⌘P</kbd></div>
  <div role="menuitem" tabindex="-1" data-highlighted>Billing <kbd>⌘B</kbd></div>
  <div role="menuitemcheckbox" aria-checked="true" tabindex="-1">Show status bar</div>
  <div role="menuitem" aria-haspopup="menu" tabindex="-1">Invite users</div>
  <div role="separator"></div>
  <div role="menuitem" tabindex="-1" data-variant="destructive">Log out</div>
</div>
```
::

## Switches, checkboxes, radios and sliders

Non-native toggles as headless libraries render them. A switch's first child is its thumb.

::blue-example
```html
<div data-layout="row">
  <button role="switch" aria-checked="true" aria-label="Airplane mode"><span></span></button>
  <button role="switch" aria-checked="false" aria-label="Wi-Fi"><span></span></button>
  <button role="checkbox" aria-checked="true" aria-label="Accept"></button>
  <button role="checkbox" aria-checked="mixed" aria-label="Select all"></button>
  <button role="radio" aria-checked="true" aria-label="Option A"></button>
  <span role="slider" tabindex="0" aria-valuenow="50" aria-label="Volume"></span>
</div>
```
::

## Toggle buttons and toolbars

`aria-pressed` makes a toggle button; `role="toolbar"` groups controls, and a separator inside it is a vertical line.

::blue-example
```html
<div data-layout="row">
  <button aria-pressed="true" aria-label="Bold">B</button>
  <button aria-pressed="false" aria-label="Italic"><i>I</i></button>
  <div role="toolbar" aria-label="History">
    <button>Undo</button>
    <div role="separator"></div>
    <button>Redo</button>
  </div>
</div>
```
::

## Select-only combobox

A `button[role="combobox"]` looks like a field with a chevron — the trigger reka-ui and Radix render for Select.

::blue-example
```html
<button role="combobox" aria-expanded="false" aria-label="Fruit">Banana</button>
<button role="combobox" aria-expanded="false" aria-label="Fruit" data-placeholder>Select a fruit</button>
```
::
