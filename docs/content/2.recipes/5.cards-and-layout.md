## Cards

Every `<article>` is a card. A `header` holds the title and description, a `footer` the actions. An `hgroup` in the header puts an action beside the title.

::blue-example
```html
<div data-layout="grid">
  <article>
    <header>
      <h3>Create project</h3>
      <p>Deploy your new project in one click.</p>
    </header>
    <p>Projects get a preview URL for every commit.</p>
    <footer>
      <button data-variant="outline">Cancel</button>
      <button>Deploy</button>
    </footer>
  </article>
  <article>
    <header>
      <hgroup>
        <h3>Notifications</h3>
        <p>You have 3 unread messages.</p>
      </hgroup>
      <button data-variant="ghost" data-size="sm">Mark read</button>
    </header>
    <progress value="66" max="100"></progress>
  </article>
</div>
```
::

## Stat cards

A `<data>` element directly in a card is the big number.

::blue-example
```html
<ul data-layout="grid">
  <li>
    <article>
      <header><p>Total revenue</p></header>
      <data value="45231.89">$45,231.89</data>
      <footer><span data-badge data-variant="success">+20.1%</span><small>from last month</small></footer>
    </article>
  </li>
  <li>
    <article>
      <header><p>Churn</p></header>
      <data value="0.032">3.2%</data>
      <footer><span data-badge data-variant="warning">+0.4%</span><small>from last month</small></footer>
    </article>
  </li>
</ul>
```
::

## data-layout

Four containers for everything structure can't express. They live in Blue's last layer, so they beat an element's own display.

| Value | Layout |
|---|---|
| `grid` | Responsive columns, at least `--blue-grid-min` (14rem) wide |
| `row` | A wrapping row with small gaps — toolbars, button rows |
| `stack` | A vertical stack with consistent gaps |
| `split` | Space between — a title on one side, actions on the other |

::blue-example
```html
<div data-layout="split">
  <strong>Invoices</strong>
  <div data-layout="row">
    <button data-variant="outline" data-size="sm">Filter</button>
    <button data-size="sm">New</button>
  </div>
</div>
<hr>
<div data-layout="stack">
  <div role="note"><strong>One</strong></div>
  <div role="note"><strong>Two</strong></div>
</div>
```
::
