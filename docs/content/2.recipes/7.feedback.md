## Alerts

`role="alert"`, `role="status"` or `role="note"` on a block element. A leading `<strong>` is the title; `data-variant` sets the tone. Empty live regions stay invisible.

::blue-example
```html
<div role="note">
  <strong>Heads up!</strong>
  <p>You can add components to your app using the CLI.</p>
</div>
<div role="alert" data-variant="destructive">
  <strong>Payment failed</strong>
  <p>Your card was declined. Please update your billing details.</p>
</div>
<div role="status" data-variant="success"><strong>Saved</strong><p>Your changes have been saved.</p></div>
<div role="note" data-variant="warning"><strong>Trial ends in 3 days</strong></div>
<div role="note" data-variant="info"><strong>Dark mode follows your system.</strong></div>
```
::

## Progress and meters

::blue-example
```html
<progress value="60" max="100"></progress>
<progress></progress>
<meter value="0.4" low="0.3" high="0.8" optimum="0.9"></meter>
<meter value="0.9" low="0.3" high="0.8" optimum="0.1"></meter>
```
::

A `<progress>` without a value is indeterminate. Meters turn green, amber or red from their `low`, `high` and `optimum`.

## Loading

An empty element with `aria-busy="true"` shows a spinner; a busy button shows one inline.

::blue-example
```html
<article aria-busy="true"></article>
<p><button aria-busy="true">Saving</button></p>
```
::
