Native elements and ARIA come first. These five attributes cover what HTML has no semantics for — the set is closed on purpose: if it kept growing, Blue would have reinvented classes.

| Attribute | Values | On |
|---|---|---|
| `data-variant` | `secondary` `outline` `ghost` `destructive` `link` | buttons |
| | `secondary` `outline` `destructive` `success` `warning` | badges |
| | `destructive` `success` `warning` `info` | alerts |
| | `destructive` | menu items, toasts |
| `data-size` | `sm` `lg` `icon` | buttons |
| `data-badge` | *(boolean)* | any inline element |
| `data-layout` | `grid` `row` `stack` `split` | any container |
| `data-blue` | `off` | any element: opts its subtree out |

## ARIA Blue reads

| Attribute | Effect |
|---|---|
| `aria-current` | Active link in navigation and breadcrumbs |
| `aria-invalid="true"` | Error state for fields and their help text |
| `aria-busy="true"` | Spinner on buttons and empty regions |
| `aria-selected` | Active tab, selected row or option |
| `aria-checked` | Switches, checkboxes, radios, checked menu items |
| `aria-pressed` | Toggle buttons |
| `aria-sort` | Sort indicator on table headers |
| `aria-disabled="true"` | Disabled look on non-native controls |
| `aria-haspopup="menu"` | Submenu chevron |
