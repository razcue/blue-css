Blue's tokens use **shadcn's names**, declared inside `@layer blue.tokens`. Define any of them in your own (unlayered) CSS — or keep your shadcn theme — and both Blue and shadcn follow it.

```css
:root {
  --primary: oklch(0.205 0 0);
  --radius: 0.5rem;
}
```
