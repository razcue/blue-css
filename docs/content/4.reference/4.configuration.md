| Option | Type | Default | |
|---|---|---|---|
| `content` | `string[]` | — | CLI: globs or directories of built output. Vite/Nuxt: extra files on top of the bundle |
| `safelist` | `string[]` | `[]` | Module ids (`'dialog'`) or tokens (`'attr:role=tab'`) that always ship |
| `presets` | `(Manifest \| string)[]` | `[]` | Extra manifests, as objects or package names |
| `reset` | `boolean` | `true` | Ship Blue's reset |
| `minify` | `boolean` | `true` | Minify the output |
| `out` | `string` | — | CLI only: output file |
| `inject` | `boolean` | `true` | Vite only: link the stylesheet from `index.html` |
| `report` | `boolean` | `true` | Vite/Nuxt: log a size summary |

## Writing a preset

A preset is a manifest: CSS files plus the tokens that trigger them.

```js
import { fileURLToPath } from 'node:url'

export default {
  name: 'my-preset',
  dir: fileURLToPath(new URL('./src/', import.meta.url)),
  layers: ['presets'],
  modules: [
    {
      id: 'my/datepicker',
      file: 'datepicker.css',
      layer: 'presets',
      triggers: ['attr:data-my-datepicker'],
      deps: ['forms'],
    },
  ],
}
```

Ids must be unique across manifests; `deps` may name core modules. Modules are wrapped in `@scope (:root) to ([data-blue="off"])` unless `scoped: false`.
